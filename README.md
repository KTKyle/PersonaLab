# PersonaLab

PersonaLab is a full-stack AI/ML platform for creating RAG-backed personas, running multi-agent simulations, and analyzing product feedback using classic ML and LLM evaluation. This is my first big personal project that mixes in all of my interests. Because of this, I want to steer clear of just vibe coding it for resume/porfolio purposes, this is for fun and for learning. Things may not be efficient or good but hopefully it will get better over time. 

## Tech Stack

- Frontend: Next.js, React, TypeScript, Tailwind, shadcn/ui
- Backend: FastAPI, Python
- Database: PostgreSQL
- Vector DB: Qdrant
- ML/AI: pandas, NumPy, scikit-learn, LangGraph / LLM APIs
- Observability: MLflow
- Future Deployment:
    * Frontend: Vercel
    * Backend: Probably Railway
    * DB: Supabase
    * Vector DB: Qdrant Cloud
